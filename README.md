# Fridge Raider

Браузерная аркада в духе Lode Runner / Milk Nuts. Офис ночью: сотрудник таскает
еду из общего холодильника, собирает продукты на трёх этажах и возвращается к
двери своего кабинета. По зданию ходят уборщик, два охранника и начальник.

Один экран, без скроллинга, прыжка нет. Только стрелки.

- Чистый Vanilla JS, ES-модули, Canvas 2D.
- Ноль зависимостей, без сборки — `index.html` открывается как есть.
- Базовое разрешение 320×240, целочисленный масштаб, `image-rendering: pixelated`.
- Фиксированный шаг симуляции 1/60 с: игра не зависит от частоты кадров монитора.

Спецификация уровня — [docs/GDD.md](docs/GDD.md) (версия 1.3).

## Управление

| Клавиша | Действие |
|---|---|
| ← → | идти влево / вправо, ползти по трубе |
| ↑ | лезть вверх по лестнице; на экранах TITLE, WIN и GAME OVER — старт и рестарт |
| ↓ | лезть вниз по лестнице, сойти с пола на лестницу, отпустить трубу |

**Только стрелки.** Других клавиш игра не перехватывает и не читает; страница
не скроллится при нажатии стрелок.

## Правила

- Собрать все 8 продуктов, затем вернуться на тайл двери `(2, 11)` на 1-м этаже.
- Жизней 3. Поимка врагом отнимает жизнь, но собранные продукты, счёт и таймер
  сохраняются; игрок возвращается в `(3, 11)`.
- Неуязвимость 1.5 с выдаётся и на старте уровня, и после каждой поимки;
  на экране `GET READY` она не расходуется.
- Урона от падения нет. Шесть люков в перекрытиях и срывы с труб доступны только
  игроку: враги ходят строго по статическому графу и в них не проваливаются.
- Очки: продукты 1400 + возвращение к двери 500 + бонус за время
  `max(0, 2000 - секунды * 10)`. Потолок формулы — 3900.

## Локальный запуск

Модули требуют HTTP: открывать `index.html` напрямую с диска (`file://`) нельзя.

```sh
cd fridge-raider
python3 -m http.server 8000
```

Затем открыть <http://localhost:8000>.

## Деплой на GitHub Pages

Репозиторий уже статический, `index.html` лежит в корне, все пути относительные.

1. Запушить ветку `main`.
2. Settings → Pages → Build and deployment → Source: **Deploy from a branch**.
3. Branch: **main**, папка: **/ (root)**. Save.
4. Через минуту игра доступна по адресу `https://<user>.github.io/<repo>/`.

Файл `.nojekyll` в корне уже добавлен, чтобы Pages не обрабатывал исходники.

## Спрайты

В `assets/sprites/` лежат 25 PNG и `manifest.json`. Чтобы заменить спрайт,
достаточно положить файл с тем же именем и той же геометрией кадра — код менять
не нужно. Если PNG нет или он не загрузился, рисуется процедурный плейсхолдер и
уровень полностью проходится без единого файла графики.
Подробности — [docs/ASSETS.md](docs/ASSETS.md).

## Структура

```
index.html               точка входа
src/main.js              канвас, масштаб, игровой цикл, ввод
src/game.js              состояния игры, счёт, победа/поражение
src/level.js             парсинг и валидация карты, запросы по тайлам
src/player.js            физика игрока (потайловое движение)
src/enemy.js             ИИ врагов: PATROL / CHASE / SEARCH
src/pathfinding.js       граф передвижения врагов и BFS
src/render.js            отрисовка мира, HUD и оверлеев, пиксельный шрифт
src/sprites.js           манифест, загрузка PNG, процедурные плейсхолдеры
src/input.js             клавиатура
data/level1.js           данные уровня 1 и параметры баланса
tools/gen-sprites.mjs    генератор стартового комплекта PNG
assets/sprites/          25 PNG-спрайтов и manifest.json
docs/GDD.md              дизайн-документ
docs/ASSETS.md           как заменить спрайты
```

Модули логики (`level`, `pathfinding`, `player`, `enemy`, `game`, `data/level1`)
не обращаются к DOM и импортируются в Node для headless-прогонов.
